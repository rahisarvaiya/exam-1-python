# Bill Splitter & Tip Calculator

A simple, beginner-friendly Python console application designed to help users calculate and split a restaurant bill with a tip among friends.

## Features

* **User Inputs & Type Casting**: Takes numeric inputs for the total bill amount, number of people, and tip percentage.

* **Validations**: Checks if the bill amount is valid (non-negative) using control structures.

* **Calculations**: Accurately computes the tip amount, final total bill, and how much each individual person needs to pay.

* **Interactive Looping**: Utilizes a `while` loop allowing users to calculate multiple bills without restarting the program.

## Requirements

* Python 3.x installed on your system.

## How to Run

1. Open your terminal or command prompt.

2. Navigate to the folder containing the project file.

3. Run the script using the following command:

   ```
   bill_splitter_RAHI.py
   
   ```
